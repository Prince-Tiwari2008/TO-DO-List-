# 📝 To-Do List
A clean, responsive, and interactive To-Do List application built using **HTML, CSS, and JavaScript**. This project helps users organize daily tasks, track their progress, and manage pending and completed activities through a simple and user-friendly interface.

## ✨ Features :-
- **Add Tasks:** Easily create and add new tasks.
- **Delete Tasks:** Remove tasks whenever needed.
- **All Tasks:** View all added tasks in one place.
- **Pending Tasks:** Filter and view tasks that are not completed.
- **Completed Tasks:** View all successfully completed tasks.
- **Dynamic UI:** Real-time updates using JavaScript DOM manipulation.
- **Responsive Design:** Clean interface suitable for different screen sizes.
- **Interactive Experience:** Smooth and user-friendly task management.

## 🛠️ Technologies Used :-
- **HTML5** – Structure of the application.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Functionality, event handling, and DOM manipulation.

## 📸 Project Overview :-
The application provides a simple way to organize everyday activities by categorizing tasks into All, Pending, and Completed sections.

## 🎯 Purpose :-
This project was developed to strengthen practical knowledge of JavaScript, DOM manipulation, event handling, and interactive web development.
